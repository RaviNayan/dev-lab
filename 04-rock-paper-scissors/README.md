# ✊✋✌️ Rock Paper Scissors

A simple, interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript. Play against the computer by choosing Rock, Paper, or Scissors and try to win as many rounds as possible.

## ✨ Features

- Three choices: Rock, Paper, and Scissors
- Randomized computer moves
- Automatic winner determination
- Separate score counters for the player and computer
- Feedback messages for wins, losses, and draws
- Interactive UI with hover effects and custom styling

## 🛠️ Built With

- **HTML5** — Game structure
- **CSS3** — Styling, layout, and hover effects
- **JavaScript** — Game logic, random choices, event handling, and score tracking

## 📚 What I Learned

- DOM manipulation and event listeners
- Generating random choices using `Math.random()`
- Implementing game logic with conditionals
- Tracking and updating scores dynamically
- Updating UI messages based on game outcomes

## 🚀 How to Run

1. Clone or download this repository.
2. Open the `04-rock-paper-scissors` folder.
3. Open `index.html` in your browser.
4. Choose Rock, Paper, or Scissors to play against the computer.

No additional dependencies or build tools are required. An internet connection is needed to load the external Google Fonts used in the design.
