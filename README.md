# 🧪 dev-lab

### A hands-on journey into web development, one project at a time.

Welcome to **dev-lab** — my collection of mini-projects, coding experiments, and practical implementations built as I learn and explore web development.

This repository documents my progress through hands-on coding. Each project helps me strengthen my fundamentals, experiment with new ideas, solve problems, and turn concepts into working applications.

## 🎯 Purpose

The goal of this repository is simple: **learn by building.**

Rather than learning technologies only through theory, I apply them through small, practical projects. This repository serves as a growing record of my development journey, the concepts I practise, and the skills I develop along the way.

## 🛠️ Core Technologies

The primary focus of these projects is gaining hands-on experience with:

- **HTML5** — Structuring webpages and organizing content.
- **CSS3** — Styling interfaces, working with layouts, and improving visual presentation.
- **JavaScript** — Understanding programming fundamentals, DOM manipulation, event handling, application logic, and interactivity.

As I progress, this repository may also include projects involving additional technologies, tools, libraries, and APIs.

## 📂 Projects

| #  | Project         | Description                                                                                | Key Learnings                                                                                          |
| -- | --------------- | ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| 01 | 🌦️ Weather App | Fetches and displays weather information for a searched city using the OpenWeatherMap API. | API integration, asynchronous JavaScript (`async/await`), JSON data, and dynamic UI updates.           |
| 02 | ✅ To-Do App     | A task management application for adding, completing, and deleting tasks.                  | DOM manipulation, event handling, dynamic element creation, and data persistence using `localStorage`. |

Each project has its own folder containing the source code and a dedicated README with further details.

## 📚 What I'm Learning

Through these projects, I'm developing practical experience in:

- Building structured webpages using HTML and styling them with CSS.
- Making webpages interactive using JavaScript.
- Manipulating the DOM and responding to user events.
- Writing functions, loops, conditional statements, and working with arrays.
- Managing application state and updating interfaces dynamically.
- Fetching data from an external API and processing JSON responses.
- Using browser storage to preserve application data.
- Breaking problems into smaller steps and debugging my code.
- Organizing projects and maintaining code using Git and GitHub.

Most importantly, I'm learning how these concepts work together to create functional applications.

## ▶️ How to Explore

1. Browse the project directories.
2. Open a project's folder to explore its source code.
3. Read its dedicated README for the features, concepts practised, and instructions for running it.
4. Try the application locally in your browser.

The current projects use plain HTML, CSS, and JavaScript, so no frontend framework or build process is required. The Weather App requires a valid OpenWeatherMap API key.
