# ❌⭕ Tic-Tac-Toe

A simple, interactive two-player Tic-Tac-Toe game built using HTML, CSS, and JavaScript. Players take turns marking a 3×3 grid with **X** and **O**, aiming to complete a winning combination.

## ✨ Features

- Interactive 3×3 game board
- Two-player gameplay with automatic turn switching
- Win detection using predefined winning combinations
- Draw detection when all nine cells are filled
- Reset Game and New Game buttons to restart the game
- Disabled cells after a move to prevent repeated selections

## 🛠️ Built With

- **HTML5** — Game structure
- **CSS3** — Styling and layout
- **JavaScript** — Game logic and interactivity

## 📚 What I Learned

- DOM manipulation and event handling
- Managing game state and player turns
- Using arrays and conditional logic
- Checking winning combinations
- Detecting draws and resetting the game

## 🚀 How to Run

1. Clone or download this repository.
2. Open the `03-tic-tac-toe` folder.
3. Open `index.html` in your browser.
4. Start playing!

No additional dependencies or build tools are required.
