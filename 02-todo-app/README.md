# ✅ To-Do List App

A simple task management application built using **HTML, CSS, and JavaScript** that lets users add, complete, and delete tasks.

## ✨ Features

- Add new tasks through an input field.
- Prevent empty task submissions.
- Mark tasks as completed.
- Delete individual tasks.
- Save tasks using browser `localStorage` so they persist across page reloads.

## 🛠️ Built With

- **HTML5** — Page structure
- **CSS3** — Styling and layout
- **JavaScript** — Application logic and interactivity
- **Local Storage** — Persisting tasks in the browser

## 📚 What I Learned

- Selecting and manipulating DOM elements using JavaScript.
- Creating and appending HTML elements dynamically.
- Handling user interactions and click events.
- Using conditional statements to validate user input.
- Toggling CSS classes to represent completed tasks.
- Using `localStorage` to save and retrieve data.
- Organizing application logic into functions.

## ▶️ How to Run

1. Clone or download the repository.
2. Open the To-Do App folder.
3. Open `index.html` in your browser.
4. Start adding and managing your tasks.

No additional dependencies or build tools are required.
