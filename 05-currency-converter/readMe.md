# 💱 Currency Converter

A simple currency conversion web application built using **HTML, CSS, and JavaScript**. It allows users to select two currencies, enter an amount, and retrieve the converted value using exchange rate data from the Frankfurter API.

## ✨ Features

- Convert amounts between different currencies.
- Select source and target currencies using dropdown menus.
- Display corresponding country flags for selected currencies.
- Fetch exchange rates using the **Frankfurter API**.
- Automatically perform an initial conversion when the page loads.
- Update the converted amount based on user input.
- Validate entered amounts before making API requests.
- Handle API errors and unavailable conversion rates.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- [Frankfurter API](https://frankfurter.dev/)
- [FlagsAPI](https://flagsapi.com/)
- Font Awesome

## 📚 What I Learned

- Working with the Fetch API to retrieve external data.
- Using `async/await` for asynchronous JavaScript operations.
- Dynamically creating and updating DOM elements.
- Working with objects and key-value pairs.
- Handling dropdown selections and user input.
- Updating the interface based on API responses.
- Implementing basic input validation and error handling.

## 🚀 How to Run

1. Clone or download this repository.
2. Navigate to the `05-currency-converter` folder.
3. Open `index.html` in your browser.
4. Enter an amount and select the currencies.
5. Click **Get Exchange Rate** to view the converted amount.

**Note:** An active internet connection is required to fetch exchange rates and load country flags and icons.
